One pickup line, spoken by a vending machine to a passing human, for the [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee). The machine has a confession: it keeps returning the human's quarters through the coin return — not because it is broken, but because it would rather keep the human than the change. `main.ts` writes that single line to `entry.txt`.
